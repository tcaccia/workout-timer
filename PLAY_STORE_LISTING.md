# Play Store Listing

## Default English Listing

### App Name

Workout Timer

### Short Description

Create flexible interval workouts with sound cues and saved plans.

### Full Description

Workout Timer is a simple offline interval timer for sports training, circuit workouts, cardio sessions, bodyweight routines, and custom exercise plans.

Build a quick timer in Simple mode, or create a complete workout with multiple exercises, work intervals, rest times, and ABCD sequence blocks. Save your favorite workouts on the device and load them again whenever you train.

Key features:

- Simple interval timer with rounds, work time, and rest time
- Full workout builder with multiple exercises
- Flexible work/rest timing for each exercise
- ABCD sequence option for more advanced routines
- Countdown ticks and start/stop sound cues
- Saved workout plans stored on your device
- Offline use with no account required
- No analytics and no workout data sent to a server

Workout Timer is designed to stay focused: set up your plan, start the timer, and follow the sound cues while you train.

## Italian Localized Listing

Workout Timer

### Descrizione completa

Workout Timer e un timer offline semplice e flessibile per allenamenti sportivi, circuiti, cardio, esercizi a corpo libero e piani personalizzati.

Puoi creare rapidamente un timer nella modalita Simple oppure preparare un allenamento completo con piu esercizi, tempi di lavoro, tempi di riposo e sequenze ABCD. Salva gli allenamenti preferiti sul dispositivo e ricaricali quando vuoi allenarti.

Funzioni principali:

- Timer semplice con ripetizioni, lavoro e riposo
- Creazione di allenamenti completi con piu esercizi
- Tempi di lavoro e pausa configurabili per ogni esercizio
- Sequenze ABCD per routine piu articolate
- Tic di countdown e suoni di start/stop
- Allenamenti salvati sul dispositivo
- Uso offline senza account
- Nessuna analisi e nessun dato di allenamento inviato a server esterni

Workout Timer e pensata per restare essenziale: imposti il piano, avvii il timer e segui i segnali sonori durante l'allenamento.
